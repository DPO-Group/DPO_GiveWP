# DPO_GiveWP

## DPO Pay GiveWP plugin v1.0.2 for GiveWP v3.19

This is the DPO Pay plugin for GiveWP. Please feel free to contact
the [DPO Pay support team](https://dpogroup.com/contact-us/) should you require any assistance.

## Installation

1. **Download the Plugin**
    - Visit the [releases page](https://github.com/DPO-Group/DPO_GiveWP/releases) and
      download [givewp-dpo.zip](https://github.com/DPO-Group/DPO_GiveWP/releases/download/v1.0.2/givewp-dpo.zip).

2. **Install the Plugin**
    - Log in to your WordPress Admin panel. Please note that **GiveWP** must be installed before activating **DPO Pay**.
    - Navigate to **Plugins > Add New > Upload Plugin.**
    - Click **Choose File** and select **givewp-dpo.**
    - Click **Install Now.**
    - Click **Activate Plugin.**

3. **Configure the Plugin**
    - Navigate to **Donations > Settings > Payment Gateways > DPO Pay**.
    - Enter your preferred data into the fields.
    - Click the **Save changes** button.
